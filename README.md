# Расписание · ТехноПортал

## Редактор версии 6.0

- В расписании видны все пары по звонкам, включая полностью свободные дни. Кнопка «+» ставит пару на выбранное время.
- В форме пары можно выбрать одну дату, следующие недели до конца семестра или года либо повторение через неделю. По умолчанию пропускаются праздники и нетeоретические дни графика; перед сохранением видны количество недель и даты. Серия сохраняется общей пачкой с возможностью удаления всей серии.
- Календарь охватывает полный учебный год, включая незаполненные недели второго семестра.
- В «Вычитке» доступны только 1 и 2 семестр, с отдельными сроками. Значение `half=0` переводится в текущий семестр. Годовой просмотр остаётся в разделе «Часы».
- Расписание можно смотреть отдельно по группе, преподавателю или аудитории (`?room=302`).
- Кнопки «Заполнить день» и «Добавить пары на неделю» открывают пакетный редактор на 5/30 слотов с общими значениями, проверкой занятых слотов и повторением.
- Справочники преподавателей и предметов доступны над расписанием и в меню администратора. Сервер `catalogSave` хранит записи на листе «Справочники» с историей прежних названий. `state.catalog` применяется к занятиям, плану и экзаменам; записи доступны публично без данных автора, запись требует сессию.
- Учебный план редактируется из «Часов» и «Вычитки»: часы и формы аттестации обоих семестров, преподаватель, новые предметы. Правки хранятся на листе «Планы», доступны через `state`, проверяются сервером и имеют откат в журнале. Расчёты, зачётка и страница преподавателя используют эффективный план.
- Экзамены редактируются по одной записи, включая дату и время пересдачи. Все 354 исходные записи перенесены в базу. `examsUrl` отключён: удалённые записи больше не появляются из JSON. Публичное чтение служебных листов запрещено.

Вход: `https://tratmik14.github.io/raspisanie/#admin`. Учётную запись создаёт владелец базы.

Сервер использует **оба** файла: `apps-script/Code.gs` и `apps-script/Plan.gs`. В редакторе Apps Script их можно разместить отдельными файлами либо объединить в один. После обновления сделайте новую версию существующего развёртывания, сохранив адрес `/exec`.

Проверки: `node tools/test_hours.js`, `node tools/test_database.js`, `node tools/test_schedule.js`, `node tools/test_admin_store.js`.

## Собственная база сайта

Расписание перенесено в отдельную Google-таблицу «ТехноПортал — база расписания»:
`1SqSkidIPZ9eFIgfINub6y3kWxBgQB8tAd3JrxXtlxw8`.

При `dataSource: 'database'` сайт читает список групп, календарь, учебный план и листы групп
через действие `table` сервера Apps Script. Обращения к старой таблице и возврата к ней
при ошибке сервера нет. Кеш данных привязан к ID новой базы.

В этой же базе сервер сохраняет правки, отмены, переносы, импортированные экзамены,
изменения графика и историю. Служебные листы, в том числе «Админы», недоступны через
публичное чтение расписания. Таблицу с учётными записями нельзя публиковать целиком.
График учебного процесса хранится в `data/` репозитория с правками из базы; экзамены полностью хранятся в новой базе.

Однократно из редактора Apps Script запускается `initializeDatabase`: она фиксирует
скопированные значения вместо формул и создаёт служебные листы. Повторно её запускать
после начала работы не нужно. Новая база далее изменяется независимо от старой.

Разверните `apps-script/Code.gs` как веб-приложение от имени владельца. Адрес `/exec`
укажите в `adminApi` в `config.js`. Google запросит разрешение на Google-таблицы;
код открывает только базу с указанным `DATABASE_ID`. Учётные записи создаются через
меню таблицы «База сайта → Добавить администратора» (в старой версии скрипта — «Расписание»).

Проверки подключения: `node tools/test_database.js`. Проверки часов: `node tools/test_hours.js`.

Ниже также описан исходный режим чтения таблицы колледжа; он относится к конфигурациям
без `dataSource: 'database'`.

Статический сайт колледжа. Расписание он берёт прямо из Google-таблицы колледжа. Замены и правки администраторов хранятся отдельно и накладываются поверх таблицы. Сайт открывается с телефона и может работать внутри ТехноПортала.

Разделы сайта:

- **Занятия.** Пары на сегодня, на завтра, на неделю или на любую дату из календаря, для группы или преподавателя. Есть чётные и нечётные недели, текущая пара подсвечена, замены выделены цветом. Над расписанием идёт лента учебного года группы из графика учебного процесса. Если с прошлого визита в таблице что-то поменялось, сайт показывает, что именно.
- **Часы.** По каждому предмету: план на семестр с листа «0 Учебные графики», сколько часов уже проведено и сколько осталось. Если выбран преподаватель, показаны все его группы.
- **Вычитка.** Для заведующего отделением: сколько пар каждой группе нужно добавить или снять, чтобы к сроку вычитать часы ровно по учебному плану. Наверху — карточки горящих групп. Считает сам сайт, без формул «Пары / Часы» в Google-таблице, и пересчитывает сразу после каждой правки.
- **График.** График учебного процесса всех групп по неделям: теория, практика, аттестация, каникулы, ГИА. Администратор может сдвигать в нём недели.
- **Экзамены.** Три страницы:
  - расписание экзаменов, зачётов и пересдач;
  - разворот зачётки студента;
  - экзамены и зачёты преподавателя.
- **Изменения.** Ближайшие замены и отмены, конфликты с таблицей, журнал правок с откатом и журнал «что изменилось в таблице колледжа».

Оформление меняет кнопка с палитрой в шапке. Тем шесть. Тёмные: «Космос», «Аврора» (северное сияние), «Закат» и «Неон». Светлые: «Рассвет» и «Дюна». Пока посетитель не выбрал тему, она следует настройке системы: при тёмной — «Космос», при светлой — «Рассвет».

## Админка

Администратор входит по логину и паролю. После входа у каждой пары появляется карандаш. Можно:

- **заменить** пару: другой предмет, преподаватель или аудитория;
- **отменить** пару;
- **перенести** пару на другой день или время;
- **поставить ещё одну пару** в то же время. Так у группы будут две пары разом, например консультация рядом с уроком подгруппы;
- **поставить пару** в свободное время кнопкой «Добавить пару».

Над неделей есть кнопка **«Массовая замена»**. Выберите преподавателя и даты, затем «передать другому преподавателю» или «отменить пары». Сайт покажет список затронутых пар и сохранит их одной пачкой. В разделе «Изменения» всю пачку можно убрать одной кнопкой.

**«Загрузить практику»** (в режиме администратора: над расписанием и на вкладке «График»; файл можно просто перетащить на страницу). Подходят Excel (.xlsx, .xls, .csv), Word (.docx) и Google-документ по ссылке. Сайт понимает два вида файлов:

- **Сроки практики.** Например «Учебный график 26-27»: на каждую группу строки «Дата начала» и «Дата окончания», колонки «Учебная практика (УП)», «Производственная практика (ПП)», «Экзамены», «Каникулы», «Преддипломная практика (ПДП)». Подходит и простой список «Группа · Вид · Начало · Окончание», и даты текстом «с 24 ноября 2026 по 7 декабря 2026». Сайт:
  - меняет эти дни в графике учебного процесса, как если бы их поправили вручную (лента года, «Часы», «Вычитка» и горящие группы сразу считают по-новому);
  - предлагает отменить обычные пары группы в дни практики и каникул. Пары самой практики («Учебная практика ПМ.02») остаются. В сроки экзаменов пары по умолчанию не отменяются;
  - показывает до сохранения, что изменится в графике («было: теоретическое обучение — 3 дня») и какие пары уйдут. Любой срок можно снять галочкой.

  Опечатку в году вроде «29.12.2026 — 11.01.2026» сайт читает как 11.01.2027. Даты-числа из Excel (46350) он тоже понимает.
- **Расписание практики по парам**: колонки «Дата», «Пара» («2 пара», «2» или «10:10-11:40»), «Наименование» (тема или вид работ), «Руководитель». Группа указывается колонкой, строкой над таблицей («группы ИС-24») или в имени файла («ИС24_…_РАСП_уп.08»). В каждый день из файла пары группы заменяются парами практики, остальные пары дня можно убрать, а в графике этот день становится днём практики. Сайт проверяет, не ведёт ли руководитель в это время пару в другой группе.

Всё сохраняется правками администратора одной пачкой: пары возвращаются в разделе «Изменения», недели — на вкладке «График» («Вернуть как в PDF»). Кнопка **«Сбросить загруженную практику»** на вкладке «График» одним нажатием убирает всё, что внесли загрузки практики: недели графика и правки пар. Ссылки на Google-таблицы, Google-документы и файлы на Диске работают так же, как у экзаменов.

Недельный шаблон без дат (как у ИС-24) больше не показывается в дни практики, сессии и каникул по графику и в праздники. Раньше он шёл каждую неделю семестра.

На вкладке **«График»** администратор нажимает на клетку недели или на карандаш у группы. Так он меняет, что идёт в эти недели: например, переносит практику с ноября на январь. Можно менять каждый день, а «как в PDF» оставляет день как в документе. Изменённые недели помечены и учитываются в ленте года и в подсчёте часов.

Таблицу колледжа сайт не трогает. Правки хранятся в отдельной Google-таблице администраторов и накладываются поверх основного расписания.

- Замены видны всем: рядом написано, что было раньше и почему пару заменили.
- **Правило приоритета.** Правка действует, пока её не сняли, даже если таблицу потом поменяли.
- **Конфликт.** Если в таблице на месте правки тоже что-то изменилось, у пары и в разделе «Изменения» появляется «Конфликт с таблицей». Там видно, что было при правке и что в таблице сейчас, и есть кнопки «Оставить правку» и «Убрать правку».
- **Журнал.** Каждое действие записывается: когда, кто, что было и что стало. Кнопка «Откатить к „было“» возвращает запись к прежнему состоянию: снимает новую правку, возвращает убранную, откатывает правку графика или прошлый список экзаменов.
- Кто внёс правку, видят только вошедшие администраторы.

Пароли нигде не хранятся в открытом виде, только хэш с солью. После 5 неверных паролей подряд логин блокируется на 15 минут. Сессия длится 6 часов.

### Тип записи, источник и время изменения

| Тип | Что это | Источник | Время |
|---|---|---|---|
| Основная | Пара из Google-таблицы расписания | лист группы, например «ИС2-25» | когда лист загружен с Google (или дата сохранённой копии) |
| Замена | Администратор поставил вместо пары другую | админка сайта; для вошедших администраторов ещё и кто | когда правку внесли или изменили |
| Ручная правка | Администратор отменил, добавил или перенёс пару | админка сайта, вид правки; для администраторов ещё и кто | когда правку внесли или изменили |

В разделе «Занятия» эти сведения показывает переключатель «Тип и источник записей». В разделе «Изменения» они стоят у каждой правки, а фильтр «Тип записи» оставляет только замены или только ручные правки. Google не сообщает, когда меняли отдельную ячейку таблицы колледжа, поэтому у основных записей указано время загрузки.

### Как подключить (один раз, примерно 10 минут)

1. Создайте новую Google-таблицу, например «Расписание — админка». Это ваша таблица, а не таблица колледжа.
2. В ней откройте **Расширения → Apps Script**. Удалите всё в редакторе, вставьте содержимое файла `apps-script/Code.gs` и нажмите **Сохранить**.
3. Нажмите **Развернуть → Новое развёртывание**. Тип: **Веб-приложение**. «Выполнять от имени»: **Я**. «У кого есть доступ»: **Все**. Нажмите **Развернуть** и разрешите доступ к своему аккаунту. Скрипт не проходил проверку Google, поэтому появится предупреждение «Приложение не проверено». Нажмите **Дополнительные настройки → Перейти на страницу «…» (небезопасно) → Разрешить**. Скрипт работает с этой таблицей, а наружу обращается только когда администратор просит прочитать Google-документ с экзаменами.
4. Скопируйте ссылку веб-приложения (заканчивается на `/exec`) и вставьте её в `config.js`, в поле `adminApi`, между кавычками.
5. Вернитесь в таблицу и обновите страницу. Появится меню **Расписание**. Выберите **Расписание → Добавить администратора**, придумайте логин и пароль (не короче 8 символов). Остальные листы скрипт создаст сам.
6. Загрузите обновлённый `config.js` на GitHub. Кнопка «Вход для администратора» в шапке теперь пускает по вашим логинам, а правки видят все.
7. Войдите на сайт и нажмите **«Обновить и импортировать»**. Первый импорт запомнит текущую версию таблицы, а следующие покажут, что в ней изменилось.

Других администраторов добавляйте так же, через меню. Там же можно сбросить пароль или отключить администратора. Отключённый администратор сразу теряет доступ. Свой пароль администратор меняет на сайте: кнопка с его именем в шапке → «Сменить пароль».

Если вы поменяли `Code.gs`, откройте **Развернуть → Управление развёртываниями → карандаш → Версия: новая версия → Развернуть**. Ссылка при этом не меняется.

Листы таблицы администраторов: «Правки», «История», «График», «Снимки», «Изменения таблицы», «Экзамены», «Экзамены (прошлая версия)», «Админы».

### Пока сервер не подключён: демо-режим

Кнопка «Вход для администратора» в шапке видна всегда. На телефоне она короче: замок и слово «Вход». Та же ссылка есть внизу страницы, а адрес `…/raspisanie/#admin` сразу открывает окно входа. Пока поле `adminApi` в `config.js` пустое, вход работает в демо-режиме: логин `demo`, пароль `demo`.

- В демо-режиме настоящий `Code.gs` запускается прямо в браузере, так что правила те же, что на сервере.
- Правки, журнал и импорт сохраняются только в этом браузере, другие посетители их не видят. Над расписанием администратор видит предупреждение об этом.
- Google-документ по ссылке в демо не читается, файлы читаются.
- Обычный посетитель, который не входил, демо не загружает и видит только основное расписание.

Чтобы правки видели все, подключите сервер по шагам выше.

## Импорт таблицы и журнал «что изменилось»

- **Сайт сам следит за таблицей.** Открытая страница перечитывает список групп, учебный план и открытые листы групп каждые 5 минут (`syncMinutes` в `config.js`, 0 — выключить). Ещё она перечитывает их, когда вкладку снова открыли. Если лист изменился, расписание на экране меняется сразу, а внизу появляется «Таблица изменилась, расписание обновлено: ИС2-25». Google иногда отдаёт свежую версию таблицы с задержкой до нескольких минут.
- **Кнопка «Обновить»** (в строке состояния под заголовком) перечитывает всё сразу. Правки администраторов подтягиваются раз в 3 минуты.
- **Правка уже внесена в таблицу.** Если в таблице теперь стоит то же, что в правке (заведующий перенёс замену в таблицу), сайт показывает пару из таблицы и не ставит её второй раз. Иначе такая пара стояла бы дважды и дважды считалась бы в часах. Эти правки видны в разделе «Изменения» → «Уже внесено в таблицу», их можно убрать одной кнопкой. В «Конфликтах с таблицей» есть кнопка «Взять из таблицы во всех».
- **«Обновить и импортировать»** у администратора делает больше:
  - читает все листы групп;
  - сравнивает каждый с версией прошлого импорта, которая хранится на листе «Снимки»;
  - записывает отличия в журнал: «ИС2-25, 29 октября, 2 пара: было «Физика…», стало «Математика…»».
- Журнал «Изменения в таблице колледжа» в разделе «Изменения» виден всем.
- Отдельно каждый браузер сравнивает таблицу с тем, что видел в прошлый раз. Над расписанием группы появляется «С вашего прошлого просмотра в таблице изменилось N пар», а такие пары помечены «Изменено в таблице».
- **Защита от поломки.** Если лист вдруг разобрался в пустоту (сменился формат, переименовали лист), новая версия не принимается. Сайт продолжает показывать прошлую, у администратора над страницей появляется предупреждение, а при импорте оно попадает в журнал. Снимок такого листа на сервере тоже не перезаписывается.
- Если пар на листе просто стало намного меньше (например, заведующий очистил недели практики), сайт показывает новую версию, а администратору пишет «проверьте лист». Раньше такая версия не принималась, и сайт продолжал показывать старое расписание.

## Вычитка часов

Вкладка **«Вычитка»** (`?view=balance`) заменяет формулы «Пары / Часы» на листах групп. Эти формулы тяжёлые, из-за них Google-таблица долго открывается и грузится не до конца. Кроме того, в них есть ошибки: у МСР-24 пары считаются с листа ОИБ-24, у ПКп-23 план взят из блока ГД-24. Сайт берёт само расписание и учебный план и считает всё сам.

- **Горящие группы** стоят первыми, карточками. Число на карточке показывает, сколько пар добавить (+) или снять (−), ниже — когда практика и сколько учебных дней до неё.
  - Группа **загорается сама** («горит: практика скоро»), если до её практики по графику учебного процесса осталось 14 дней или меньше (`urgentDays` в `config.js`), а пары ещё не вычитаны. Если теория уже закончилась, а пары так и не вычитаны, — «горит: теория прошла». Когда пары добавят, группа гаснет сама. Если на вкладке «График» перенести практику, срок сдвинется вместе с ней.
  - Группы, которые горят всегда, перечислены в `config.js`, в поле `urgentGroups`. Сейчас там ТМ-24, ПК-23, ПКп-23, МСР-24, СПм-25 и ОДЛу-24.
- **По каждому предмету** видно: план семестра, сколько проведено, сколько ещё стоит в расписании до срока и разница «план − расписание». Знак у разницы тот же, что в таблице: больше нуля — пары нужно добавить, меньше нуля — снять. Рядом написано, что сделать, например «Добавить 3 пары, ≈ 1 пара в неделю».
- **Срок вычитки.** По умолчанию это последний день теории по графику учебного процесса. Кнопка «Перед сессией» переносит срок на последний день перед сессией: так засчитываются пары, которые ставят в дни практики. Можно выбрать и свою дату. Пары после срока, а также пары в праздники (4 ноября и др., поле `holidays`) не засчитываются, и сайт пишет, сколько их.
- **Подобрать время** (у администратора). Сайт показывает свободные пары, когда свободны и группа, и преподаватель. Занятость преподавателя проверяется по всем группам. Первыми идут пары встык к тем, что уже стоят, чтобы не было окон. Кнопка «Поставить» добавляет пару правкой администратора.
- **Какие снять** (у администратора). Сайт показывает последние будущие пары предмета, и любую можно отменить одной кнопкой.
- **Пересчёт сам.** После каждой правки (добавили, отменили, перенесли пару, массовая замена) числа на вкладке сразу меняются. Все правки видны в разделе «Изменения», их можно откатить.
- **«Все группы»** — сводка по всем 35 группам: сколько пар добавить или снять, срок и до какого дня заполнена таблица. Кнопка «Скачать для Excel» сохраняет таблицу группы или сводку в CSV.

Практика (УП, ПП) идёт неделями по графику, парами она не вычитывается. Поэтому если её нет в расписании, она не попадает в «не хватает».

## Как считаются часы

- **План** берётся с листа «0 Учебные графики»: для каждой группы колонки «в 1 сем.» и «во 2 сем.» (в ячейке «3/46» план — 46 часов), практика, форма отчёта и преподаватель. Колонки сайт находит по заголовкам.
- **Проведено** — пары по этому предмету, которые уже закончились, по 2 часа за пару (`hoursPerPair` в `config.js`). Одна пара сразу для обеих подгрупп считается один раз. Если подгруппы занимаются в разное время, часы считаются по каждой подгруппе отдельно, и в зачёт идёт та, у которой пар больше: часы не удваиваются. Отменённые пары не считаются, поставленные и заменённые считаются.
- Если в учебном плане часы за год стоят в колонке 1-го семестра, а во 2-м записано «9/144», они относятся ко 2-му семестру. Предмет, вставленный в блок плана дважды, считается один раз.
- **Осталось** = план − проведено.
- Названия в расписании и в плане сопоставляются по коду дисциплины, по сокращению и по словам. Сейчас так сопоставлено 351 из 363 названий. Остальные 12 — с листа ТАКХС-24, где стоят предметы 1-го курса.
- Семестр сайт делит по графику учебного процесса: второй начинается с недели после зимних каникул. Чёрточка на полосе показывает, какая доля теоретических дней уже прошла.

## График учебного процесса

PDF-графики разобраны программой `tools/parse_grafik.py` в файл `data/grafik.json`. У каждой группы 5 строк-дней и 44 недели с 1 сентября. Знаки легенды:

- `::` — аттестация;
- `=` — каникулы;
- `0` — учебная практика;
- `8` — производственная практика;
- `х` — преддипломная практика;
- `Δ` — подготовка к ГИА;
- `III` — ГИА.

Правки администраторов хранятся отдельно, на листе «График», поэтому `grafik.json` не меняется.

Особенности текущих PDF:
- «ПК-2З» записана с русской буквой З;
- «ОДЛу -24» — с пробелом;
- ГД-24 указана дважды, вторая запись — это ГДп-24;
- «ПДп-22» — это ПДп-26.

На следующий учебный год положите новые PDF в `data/pdf/` и запустите (нужен Python 3):

```
pip install pdfplumber
python tools/parse_grafik.py --check data/pdf/grafik-1-kurs.pdf data/pdf/grafik-2-kurs.pdf data/pdf/grafik-3-kurs.pdf data/pdf/grafik-4-kurs.pdf
python tools/parse_grafik.py data/pdf/grafik-1-kurs.pdf data/pdf/grafik-2-kurs.pdf data/pdf/grafik-3-kurs.pdf data/pdf/grafik-4-kurs.pdf > data/grafik.json
```

## Экзамены

- **Расписание экзаменов** складывается из трёх источников:
  - лист `Экзамены` в таблице колледжа, если он есть;
  - Word-графики экзаменов и зачётной недели, разобранные в `data/exams.json`;
  - список, который администратор загрузил из документа.
- **Общее расписание показывает только экзамены.** Зачёты, дифференцированные зачёты и пересдачи в него не попадают. Их можно открыть кнопками «Зачёты», «Диф. зачёты» и «Пересдачи». Напоминание над расписанием пар тоже говорит только об экзаменах.
- **«Загрузить таблицу экзаменов»** (у администратора, в разделе «Экзамены»). Файл можно просто перетащить на страницу экзаменов или в окно загрузки. Подходят:
  - Excel (.xlsx, .xls, .csv);
  - Word (.docx);
  - ссылка на Google-таблицу, Google-документ или файл на Google Диске с доступом «Все, у кого есть ссылка → Читатель».

  Ссылку браузер сначала открывает сам: так она работает и в демо-режиме. Из Google-таблицы читаются все листы, а если Google их не отдаёт — лист, на который указывает ссылка (`#gid=…`). Если Google не отдал файл совсем, его забирает сервер правок, когда он подключён. После обновления `Code.gs` сделайте новую версию развёртывания. Без сервера сайт подскажет скачать файл и загрузить его.

  Подходят и графики колледжа «Графики экзаменов…» и «График зачётной недели…». В них группа стоит строкой «группы № …» над таблицей, а экзамен это или зачёт, видно по заголовку документа. Слово «диф» в названии делает строку диф. зачётом, а название, перенесённое на следующую строку, склеивается. Старый формат Word (.doc) браузер не читает: сохраните документ как .docx. Обычная таблица — колонки «Группа», «Дисциплина», «Дата и время», «Аудитория», «Преподаватель», «Тип аттестации».

  Перед сохранением сайт сверяет каждую строку со всем, что знает, и показывает итог:
  - **что изменится**: новая запись, изменится (было — стало) или без изменений, а также что уберётся с сайта, потому что этого нет в новой таблице;
  - **группа и преподаватель**: есть ли они в списке групп и в расписании. «ПК-2З» с русской З и «ОДЛу -24» с пробелом приводятся к виду из списка групп, «Иванова А. С.» — к «Иванова А.С.»;
  - **учебный план**: есть ли предмет у группы и совпадает ли форма. Например: «по учебному плану в 1-м семестре — диф. зачёт, а в таблице — экзамен»;
  - **дата**: воскресенье, праздник, прошедшая дата, а также что в этот день по графику учебного процесса, если не аттестация;
  - **накладки**: у группы два экзамена в один день, преподаватель в это время принимает другой экзамен или ведёт пару в другой группе, аудитория занята;
  - **пары в часы экзамена**: их сайт предлагает отменить, галочки можно снять. Экзамен идёт `examMinutes` минут (в `config.js`, по умолчанию 240), зачёт — одну пару.

  Кнопка «Применить» меняет экзамены **только тех групп, что есть в таблице**, и только в эту сессию (±30 дней от дат таблицы). Экзамены остальных групп и прошлых сессий остаются. Загруженная таблица важнее листа «Экзамены» и `data/exams.json` для этих групп в эти дни. Прошлый список экзаменов возвращает кнопка «Откатить» в журнале, отменённые пары — раздел «Изменения».
- **«Сбросить загруженные»** (рядом с загрузкой) убирает все загруженные экзамены и зачёты и возвращает пары, отменённые под них. Экзамены из таблицы колледжа и `data/exams.json` остаются. Если сбросили по ошибке, список возвращается кнопкой «Откатить» в журнале правок.
- Кнопка **«Шаблон»** скачивает пустую таблицу в нужном формате. Шаблоны и готовые примеры лежат и в папке `shablony/`, ссылки на них есть в окне загрузки.
- Обязательны только **дисциплина и дата**. Если не указана группа, берётся группа, выбранная на странице экзаменов. Если не указан тип, строка записывается как экзамен. Сайт об этом пишет у каждой такой строки. Даты-ячейки Excel читаются в любом виде, в том числе «12/23/2026». Пустой шаблон сайт тоже узнаёт и просит заполнить строки.
- **Зачётка студента.** Разворот зачётной книжки группы за семестр: слева экзамены, справа зачёты и дифференцированные зачёты, с часами и преподавателем по учебному плану и датами из расписания экзаменов. Колонок для оценок и подписей в ней нет.
- **Преподавателю.** Все экзамены и зачёты преподавателя по учебным планам групп и расписанию экзаменов.
- В зачётку текущего учебного года попадают только записи с 1 августа этого года. Сессии прошлого года видны в расписании и на странице преподавателя.

Как обновить `data/exams.json` из новых Word-графиков. Нужен `antiword`, он входит в Git для Windows. Сначала сверьте таблицу глазами, потом запишите файл:

```
python tools/parse_exams.py --check "Графики экзаменов ... .doc" "график_зачетной_недели ... .doc"
python tools/parse_exams.py --period="1 семестр 2026/2027 учебного года" "Графики экзаменов ... .doc" "график_зачетной_недели ... .doc" > data/exams.json
```

Программа находит группу по строке «группы № …» над таблицей. Тип записи она берёт из заголовка документа: «экзаменационной сессии» — экзамен, «зачетной недели» — зачёт. Строки, которые не удалось прочитать, она перечисляет в окне команд.

Формат листа `Экзамены` (ТЗ, БП 5.5):

| № | Группа | Дисциплина | Дата и время проведения | Аудитория | Преподаватель | Тип аттестации | Дата и время пересдачи |
|---|---|---|---|---|---|---|---|
| 1 | ИС2-25 | Математика | 23.06.2027 10:00 | 402 | Куликова О.В. | Экзамен | 10.07.2027 10:00 |

## Внутри ТехноПортала

Добавьте к адресу `?embed=1`. Тогда у сайта не будет своей шапки и подвала, а свою высоту он сообщит странице портала. Пример страницы портала: `tools/portal-embed.html` (на сайте: `tratmik14.github.io/raspisanie/tools/portal-embed.html`). В React-портале это выглядит так:

```tsx
import { useEffect, useRef, useState } from 'react';

export default function SchedulePage() {
  const frame = useRef<HTMLIFrameElement>(null);
  const [height, setHeight] = useState(900);
  useEffect(() => {
    const onMessage = (e: MessageEvent) => {
      if (e.source === frame.current?.contentWindow && e.data?.type === 'raspisanie:height') setHeight(Math.max(400, Math.ceil(e.data.height)));
    };
    window.addEventListener('message', onMessage);
    return () => window.removeEventListener('message', onMessage);
  }, []);
  return <iframe ref={frame} src="https://tratmik14.github.io/raspisanie/?embed=1" title="Расписание" style={{ width: '100%', height, border: 0 }} />;
}
```

Группу можно передать сразу: `?embed=1&group=ИС2-25`. Вход для администратора во встроенном виде скрыт, править расписание удобнее на самом сайте.

## Таблица расписания

Что сайт прощает листам групп, чтобы ничего не потерялось:

- **Строка дней недели повторена два раза подряд** (так у ПКп-24). Это одна неделя. Раньше такая неделя пропадала целиком, у ПКп-24 так терялись все нечётные недели.
- **У недели нет строки с датами** (ТМ-26, неделя 3; ОДЛу-24, недели 19–36). Даты берутся по подписи «Неделя N», а если её нет, неделя идёт за предыдущей.
- **Google не ответил с первого раза.** Сайт спрашивает лист ещё дважды с паузой и грузит не больше 4 листов одновременно.
- **Сайт читает только колонки A–I** листа группы (`groupSheetRange` в `config.js`). Формулы и план справа ему не нужны, а без них Google отвечает быстрее.

- Доступ к таблице: «Все, у кого есть ссылка → Читатель».
- На следующий семестр, если расписание будет в другой таблице, поменяйте `sheetId` в `config.js`. Это часть ссылки на таблицу между `/d/` и `/edit`.
- Лист **«Список групп»**: в колонке A перечислены группы, лист каждой группы называется так же, как группа.
- Лист **«0 Календарь»**: недели семестра с пометкой «четная»/«нечетная».
- Лист **«0 Учебные графики»**: учебные планы групп.
- На листе группы каждая неделя устроена так: строка с датами, строка с днями недели, затем строки пар. Ячейка пары: дисциплина, преподаватель и аудитория, каждое на своей строке. Подгруппы разделяются пустой строкой.
- Если на листе группы нет дат, как сейчас у ИС-24, недельный шаблон повторяется на все недели теории по графику учебного процесса (кроме праздников), и сайт об этом предупреждает.

## Если что-то не загрузилось

Браузер хранит последнюю копию расписания, учебного плана и правок. Если Google не ответил, сайт покажет эту копию с жёлтой пометкой, временем загрузки и кнопкой «Повторить».
